## Добавление подписки 🔗

1. Откройте FlClash → раздел **«Профили» / «Profiles»**
2. Нажмите **«+»** → **«Импорт из URL»**
3. Вставьте ссылку на подписку от провайдера
4. **«Сохранить»** → дождитесь загрузки → активируйте профиль

> 💡 Скачивайте только с официальных источников: сайт [amnezia.org](https://amnezia.org) или GitHub-репозиторий разработчика.

## 🔗 Подключение

### Вариант 1 — готовый конфиг (файл или ссылка)
1. Откройте Amnezia VPN.
2. Нажмите **«+»** / **«Добавить»**.
3. Выберите **«Импорт из файла»** или **«Импорт из ссылки»** (vpn://).
4. Укажите файл/ссылку от провайдера или свой конфиг.
5. Нажмите **«Подключиться»** и разрешите VPN в запросе системы.
