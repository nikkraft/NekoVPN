# FlClash VPN — короткий гайд

Краткая инструкция по скачиванию FlClash и добавлению подписки.

> ⚠️ **Перед использованием обязательно прочитайте дисклеймер.**

## Скачивание 📥

| Платформа | Где взять |
|-----------|-----------|
| Android | Google Play или [GitHub Releases](https://github.com/chen08209/FlClash/releases) — `FlClash` |
| Windows / macOS / Linux | [GitHub Releases](https://github.com/chen08209/FlClash/releases) — файл под вашу ОС (`.exe`, `.dmg`, `.AppImage`) |
| iOS | FlClash нет — используйте Streisand или Shadowrocket |

## Добавление подписки 🔗

1. Откройте FlClash → раздел **«Профили» / «Profiles»**
2. Нажмите **«+»** → **«Импорт из URL»**
3. Вставьте ссылку на подписку от провайдера
4. **«Сохранить»** → дождитесь загрузки → активируйте профиль

> 💡 FlClash — клиент, сам по себе доступа к интернету не даёт: нужна подписка от провайдера или свой сервер.
