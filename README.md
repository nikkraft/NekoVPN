##Nikkraft Vpn V2
Перезапуск проекта в виде конфигурации-ускорителя, совместимой с клиентами FLClash и AmneziaVPN.
Подключение по ссылке с автообновлением профиля. 
В FLClash — ядра Clash с правилами маршрутизации, в AmneziaVPN — современные протоколы передачи (AmneziaWG, XRay). Один конфиг — два клиента.
